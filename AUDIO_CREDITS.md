# Chord Flow audio credits

## Pitched samples
FluidR3 GM by Frank Wen, rendered to MP3 by gleitz/midi-js-soundfonts. Source: https://github.com/gleitz/midi-js-soundfonts/tree/gh-pages/FluidR3_GM . The source README identifies FluidR3 GM as CC BY 3.0: https://creativecommons.org/licenses/by/3.0/ . Original SoundFont: https://packages.debian.org/stable/fluid-soundfont-gm (see package copyright). Chord Flow extracts a subset of the pre-rendered MP3 notes into JSON base64 banks and transposes them during playback. No claim of ownership of original recordings. Files: electric_piano_1-mp3.js, acoustic_grand_piano-mp3.js, electric_bass_finger-mp3.js.

## Drums
Michael Fischer, Technopolis, Roland TR-808 Rhythm Composer Sound Sample Set 1.0.0 (1994), hosted by tidalcycles/sounds-tr808-fischer (https://github.com/tidalcycles/sounds-tr808-fischer). Repository license CC0 1.0: https://github.com/tidalcycles/sounds-tr808-fischer/blob/main/LICENSE . WAV files bd8/BD0000.WAV, sd8/SD0000.WAV, ch8/CH.WAV fetched at runtime from the public repository. Synthetic fallback generated by Chord Flow.
